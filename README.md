# Sales Performance Analysis

## 📌 Project Overview

This project focuses on analyzing sales data to understand overall sales performance, product and category trends, customer behavior, and regional performance.

The project follows an end-to-end data analytics workflow using **Python, SQL, Excel, and Power BI** — from data preparation and analysis to interactive visualization and business insights.

---

## 🎯 Objectives

* Analyze overall sales and revenue performance.
* Identify sales trends and patterns.
* Evaluate product and category performance.
* Analyze customer segments and purchasing behavior.
* Compare sales performance across different regions.
* Identify key business KPIs and performance indicators.
* Build an interactive Power BI dashboard for data-driven decision-making.

* KPI cards
